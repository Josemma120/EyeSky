# Dataset de Rostros para EyeSky

Coloca aquí las carpetas con las fotos de las personas autorizadas (hasta 8 personas).
El nombre de cada carpeta será el nombre con el que el sistema identificará a la persona.

Ejemplo:
dataset/
├── Emmanuel/
│   ├── foto1.jpg
│   └── foto2.jpg
├── Janeth/
│   ├── foto1.jpg
│   └── foto2.jpg
└── Moises/
    ├── foto1.jpg
    └── foto2.jpg

Consejo:
- Entre 1 a 3 fotos claras y de frente por persona son suficientes para ArcFace.
- Formatos admitidos: .jpg, .jpeg, .png
